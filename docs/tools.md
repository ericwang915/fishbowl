## Desktop

### `computer`

Pixel-level control of the 1280x800 desktop via xdotool. Coordinates are screen pixels. `key` uses xdotool names, e.g. "Return", "ctrl+l", "ctrl+shift+t". Returns a screenshot after acting.

| param | type | default |
|---|---|---|
| `action` | `screenshot` \| `left_click` \| `right_click` \| `middle_click` \| `double_click` \| `mouse_move` \| `left_click_drag` \| `type` \| `key` \| `scroll` \| `cursor_position` \| `wait` | **required** |
| `x` | integer? | `null` |
| `y` | integer? | `null` |
| `x2` | integer? | `null` |
| `y2` | integer? | `null` |
| `text` | string? | `null` |
| `key` | string? | `null` |
| `direction` | `up` \| `down` \| `left` \| `right` | `'down'` |
| `amount` | integer | `3` |
| `seconds` | number | `1.0` |
| `screenshot_after` | boolean | `True` |

### `shell`

Run a bash command inside the VM (cwd /workspace, DISPLAY=:1). Only /workspace is shared with the Mac.

| param | type | default |
|---|---|---|
| `command` | string | **required** |
| `timeout_s` | number | `60` |

### `clipboard_get`

Read the VM clipboard (it is kept in sync with the Mac clipboard).


### `clipboard_set`

Set the VM clipboard (syncs to the Mac clipboard too).

| param | type | default |
|---|---|---|
| `text` | string | **required** |

## Human in the loop

### `view_screen`

Open the live viewer (noVNC + Pause/Resume) in the Mac browser. Does nothing if it is already open.


### `handoff`

Give the screen to the human (to log in, solve a captcha, decide something). Blocks until they click "Done" in the viewer or the timeout passes; returns any note they typed.

| param | type | default |
|---|---|---|
| `reason` | string | **required** |
| `timeout_s` | number | `600` |

### `control_status`

Is the agent paused, is a handoff in progress, is the viewer open?


## Browser (CDP)

### `browser_open`

Navigate the working tab to a URL and wait for the page to settle.

| param | type | default |
|---|---|---|
| `url` | string | **required** |

### `browser_read`

The visible text of the working tab (url, title, text).

| param | type | default |
|---|---|---|
| `max_chars` | integer | `20000` |

### `browser_elements`

Interactive elements as a table: [id] role "name" value=… checked=…, plus screen coordinates for `computer`. Use the ids with browser_click / browser_type / browser_select.

| param | type | default |
|---|---|---|
| `only_in_viewport` | boolean | `False` |

### `browser_click`

Click an element by id. Checks it is still there and not covered first. Irreversible or public actions (pay, send, delete, submit…) need human approval — pass approved=true only after the user said yes.

| param | type | default |
|---|---|---|
| `element` | integer | **required** |
| `approved` | boolean | `False` |

### `browser_type`

Type text straight into an element (no keystroke jitter). submit=true presses Enter afterwards. Card numbers and API keys are always refused.

| param | type | default |
|---|---|---|
| `element` | integer | **required** |
| `text` | string | **required** |
| `clear` | boolean | `True` |
| `submit` | boolean | `False` |
| `approved` | boolean | `False` |

### `browser_select`

Choose an option (by visible text or value) in a <select> dropdown.

| param | type | default |
|---|---|---|
| `element` | integer | **required** |
| `option` | string | **required** |

### `browser_scroll`

Scroll the working tab by `amount` screen heights.

| param | type | default |
|---|---|---|
| `direction` | `up` \| `down` | `'down'` |
| `amount` | number | `0.8` |

### `browser_press`

Press a key in the working tab. Enter goes through the approval guard.

| param | type | default |
|---|---|---|
| `key` | `Enter` \| `Tab` \| `Escape` \| `Backspace` | **required** |
| `approved` | boolean | `False` |

### `browser_overlays`

Find popups, modals, cookie banners or chat widgets covering the page, with ids of their dismiss buttons.


### `browser_wait`

Wait until the page stops changing (DOM quiet for quiet_ms) or timeout.

| param | type | default |
|---|---|---|
| `quiet_ms` | integer | `600` |
| `timeout_ms` | integer | `10000` |

### `browser_tabs`

List tabs. `working` marks the tab every browser_* tool acts on.


### `browser_tab`

Open a new working tab, switch the working tab, or close a tab. Tabs a site opens by itself never become the working tab unless you switch to them.

| param | type | default |
|---|---|---|
| `action` | `new` \| `switch` \| `close` | **required** |
| `tab_id` | string? | `null` |
| `url` | string | `'about:blank'` |

### `browser_back`

Go back in the working tab's history.


## Fast execution

### `browser_run`

Execute a multi-step web plan locally with the fast decision model. You write the plan; it acts. plan: [{"goal": "search for 'usb c hub'", "text": "usb c hub"}, {"goal": "open the first result"}, …] Only `text` written in the plan is ever typed. Returns status done | handback | needs_approval | paused | timeout | error, with the reason and a step log. `allow` pre-approves guard categories such as ["send_message"] when the user already agreed.

| param | type | default |
|---|---|---|
| `plan` | object \| string?[] | **required** |
| `timeout_s` | number | `180` |
| `allow` | string[]? | `null` |

## Chatbot QA

### `chat_ask`

Ask a web chatbot one question on the current page: types it, confirms it shows up in the conversation, waits for the reply to settle (ignoring "Thinking…" style placeholders) and labels the outcome: answered | no_reply | survey_only | placeholder_stuck | send_failed | blocked.

| param | type | default |
|---|---|---|
| `message` | string | **required** |
| `input_selector` | string? | `null` |
| `send_selector` | string? | `null` |
| `timeout_s` | number | `60` |

### `judge_reply`

Grade a chatbot reply: reply type, language match, actionable, cites store data, score 1-5, issues. Pass chat_ask's label; no_reply/survey_only are graded by rule without a model call.

| param | type | default |
|---|---|---|
| `question` | string | **required** |
| `reply` | string | **required** |
| `label` | string? | `null` |
| `expected_language` | string? | `null` |
| `store_context` | string? | `null` |

### `model_stats`

Decision-model usage: calls, tokens, latency and spend, split by purpose (decide, check, guard, judge).

| param | type | default |
|---|---|---|
| `since_hours` | number? | `null` |
